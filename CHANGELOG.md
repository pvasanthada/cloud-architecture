# Changelog

All notable changes to this repository are documented here.
This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-07-31

### Added
- Initial public release of the Cloud Architecture knowledge base.
- Architecture principles: design principles, ADR practice, enterprise architecture, cloud adoption framework, platform engineering.
- Nine cloud architecture patterns (hub-spoke through hybrid-cloud).
- Ten architecture domain deep-dives (networking through disaster recovery).
- Five realistic ADRs plus a reusable ADR template.
- Six complete reference architectures spanning Azure, GCP, hybrid, AI, and Kubernetes.
- Six Draw.io architecture diagram sources.
- Six best-practice checklists.
- Five realistic enterprise case studies.
- Curated reference reading list across books, Microsoft, Google, CNCF, and architecture frameworks.

### Notes
- This is a knowledge base intended for learning and architecture-decision reference, not a deployment repository — see the companion `gcp-landing-zone` and `terraform-enterprise` repositories for runnable Terraform.
